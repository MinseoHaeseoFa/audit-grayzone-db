# 공공·출연연 감사 그레이존(Borderline) 전문 판례 DB

> 한국생산기술연구원(KITECH) 및 공공기관 내부감사 의사결정 지원 인터랙티브 웹 애플리케이션

## 🚀 개요
본 시스템은 공공기관 및 정부출연연구기관(R&D) 내부감사 실무에서 판단이 애매한 경계선(그레이존) 사건들을 6대 핵심 감사 영역별로 분류하고, 합법과 위법을 가른 법리적 분기점(Turning Point)과 실무 체크포인트를 제공합니다.

## 🎯 6대 핵심 감사 영역
1. **🔬 R&D 연구비**: 학생인건비 풀링제, 시약·재료비 허위청구, 과제 종료 임박 예산 소진 등
2. **💡 기술료·지재권**: 스핀오프 창업기업 직무발명 유출, 기술료 분납 연체 및 담보 미징구 등
3. **🛒 계약·수의계약**: 2천만 원 이하 쪼개기 분할발주, 특정 외산 모델 스펙 알박기 등
4. **🚨 복무·이해충돌**: 중소기업 기술지원 후 사후 자문료 수령, 배우자 회사 수의계약 등
5. **🛡️ 적극행정 면책**: 공급망 위기 시 장비도입심의 사후 추인, 사전컨설팅 감사 면책
6. **👥 HR·직장 내 괴롭힘**: 저성과 연구자 과제 배제 재량 vs 표적 업무 배제 등

## 🛠️ 기술 스택 및 구조
- **Frontend**: Single-Page Application (HTML5, Tailwind CSS, Vanilla JS, FontAwesome)
- **Zero-Dependency**: 빌드 도구 없이 `index.html` 단일 파일로 동작
- **기능**: 실시간 키워드 검색, 카테고리/판정결과 필터링, 카드뷰 ↔ 테이블뷰 토글, 상세 분석 모달 팝업, 로컬 즐겨찾기(LocalStorage), 데이터 내보내기(JSON)

## 🌐 깃허브 및 버셀(Vercel) 배포 방법 (1분 완성)
1. **깃허브 리포지토리 생성**:
   - GitHub에서 새 레포지토리 `audit-grayzone-db` 생성
   - 본 폴더의 파일들을 커밋 및 푸시
2. **버셀(Vercel) 연동 배포**:
   - [vercel.com](https://vercel.com) 로그인 (GitHub 계정 연동)
   - `Add New Project` → 방금 생성한 `audit-grayzone-db` 레포지토리 선택
   - 빌드 설정 없이 `Deploy` 클릭 (정적 웹사이트 자동 감지)
3. **배포 완료**:
   - `https://audit-grayzone-db.vercel.app` (또는 사용자 지정 도메인) 생성
   - 감사 관계인들에게 URL 전달하여 즉시 활용
